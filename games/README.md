# SiPra Games – Mini-game modules

Each folder is one game. Rebuild by replacing `game.js` and/or `style.css`.

## Per game folder
- `game.js` – logic
- `style.css` – styles for that game only
- `README.md` – contract for ChatGPT / Gemini

## Shared
- `_kit/game-kit.js` – helpers (`SiPraGameKit`)
- `_kit/games-shared.css` – shared arena / particles / feedback
